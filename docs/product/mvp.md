# MVP

## Goal

Deliver the first usable operational core of the school ERP without runtime AI dependencies.

## MVP capabilities

- manage campuses and programs;
- create and manage cohorts;
- register learners and their enrollments;
- assign staff/SWE to campuses and cohorts;
- manage exam definitions, sessions and attempts;
- record attendance;
- display canonical operational metrics;
- enforce authentication, roles and permissions;
- expose the required features through the web UI and API.

## First vertical slice

Active learner counts by campus and cohort, calculated from enrollment state rather than raw learner rows.
