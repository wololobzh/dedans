# Domain map

Initial bounded modules:

- school-structure: campuses, programs, cohorts
- learners: learner identity and enrollments
- staff: staff and assignments
- attendance: attendance records
- exams: exams, sessions, attempts
- analytics: canonical metric queries/read models
- identity-access: users, roles, permissions

The exact package layout may evolve, but these concepts should not be casually merged in the UI or prompt layer.
